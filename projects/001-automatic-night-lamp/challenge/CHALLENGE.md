# Automatic Night Lamp — Challenge

## Problem

A lamp normally requires a person to manually switch it on and off.

Design a system that can automatically determine when a lamp should turn on based on the surrounding light level.

## Challenge

Build an automatic night lamp that:

- Detects the surrounding light level.
- Turns the lamp ON when the environment becomes sufficiently dark.
- Turns the lamp OFF when sufficient light returns.
- Operates without continuous human control.
- Responds reliably to changing light conditions.

## Constraints

The solution should:

- Use commonly available electronic components.
- Have a clearly defined input and output.
- Be electrically safe.
- Avoid unnecessary complexity.
- Operate repeatedly rather than only demonstrating the behavior once.

## Unknowns

Do not assume a specific implementation.

Determine through research and experimentation:

- How light should be detected.
- Which sensor or sensing method is appropriate.
- How the sensor signal should be interpreted.
- How the switching mechanism should work.
- How the threshold should be determined.
- How false switching can be prevented.
- What power supply is appropriate.
- How the system should behave during changing light conditions.

## Success Criteria

The finished system should:

1. Detect darkness reliably.
2. Turn the lamp ON at the defined threshold.
3. Turn the lamp OFF when the environment becomes sufficiently bright.
4. Avoid rapid ON/OFF switching near the threshold.
5. Continue operating reliably over repeated cycles.
6. Have measurable and documented performance.

## Rule

Do not copy a finished circuit and call the project complete.

Understand the problem first.

**Think → Build → Test → Break → Understand → Improve**
