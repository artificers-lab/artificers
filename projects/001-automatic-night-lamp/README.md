# Project 001 — Automatic Night Lamp

## Status

Challenge / Research

## Description

An engineering project to design and build a system that automatically controls a lamp according to the surrounding light level.

## Objective

Create a reliable automatic lighting system that detects environmental brightness and switches the lamp appropriately without continuous human control.

## Current Stage

The problem has been defined.

The implementation has intentionally not been predetermined.

The next stage is research into possible sensing, control, switching, and power architectures.

## Project Structure

- `challenge/` — Problem and challenge definition
- `docs/` — Engineering documentation and project history
- `hardware/` — Hardware-related files
- `firmware/` — Embedded firmware
- `software/` — Supporting software
- `testing/` — Tests, measurements, and results
- `resources/` — Technical references and project resources

## Engineering Rule

**Build it. Break it. Find out why. Fix it. Test it again.**

A successful demonstration is the beginning of completion, not the definition of it.
