ARTIFICERS

Initial Project Specifications

01. AUTOMATIC NIGHT LAMP

Job:
Automatically control a lamp according to ambient light.

Core Work:
Detect surrounding light and switch the lamp ON when it becomes dark and OFF when sufficient light returns.

Functions:

- Detect ambient brightness.
- Automatically turn the lamp ON below a defined threshold.
- Automatically turn it OFF above the threshold.
- Allow manual ON/OFF control.
- Prevent rapid ON/OFF switching near the threshold.
- Operate continuously without human intervention.
- Provide safe and stable power to all components.

Completion:
Works reliably under changing real-world lighting conditions, not only in a controlled demonstration.

---

02. SMART DUSTBIN

Job:
Detect a person approaching the bin, open its lid automatically, and monitor its fill level.

Core Work:
Use sensors, a controller, and an actuator to automate the bin.

Functions:

- Detect a person/object near the bin.
- Open the lid automatically.
- Keep the lid open for an appropriate period.
- Close the lid automatically.
- Detect whether the bin is becoming full.
- Indicate the fill level.
- Prevent unnecessary lid movement.
- Detect abnormal sensor readings.
- Continue basic operation if non-critical functionality fails.
- Use a safe and reliable power system.

Completion:
Repeatedly detects, opens, closes, and measures the bin without manual intervention.

---

03. AUTOMATIC PLANT WATERING SYSTEM

Job:
Automatically water a plant when its soil becomes too dry.

Core Work:
Measure soil moisture and control a water pump according to the plant's requirements.

Functions:

- Measure soil moisture.
- Determine whether watering is required.
- Activate the pump when necessary.
- Stop watering after reaching the required moisture level or safety limit.
- Prevent continuous pumping.
- Detect an empty water reservoir.
- Detect abnormal sensor/pump conditions.
- Provide manual watering control.
- Record watering events.
- Operate continuously without supervision.

Completion:
Maintains suitable soil moisture without overwatering or requiring manual operation.

04. DIGITAL COMBINATION LOCK

Job:
Provide controlled access using a digital password.

Core Work:
Accept an entered code, verify it, and control a physical locking mechanism.

Functions:

- Accept password input.
- Verify the entered password.
- Unlock when the correct password is entered.
- Reject incorrect passwords.
- Limit repeated incorrect attempts.
- Provide a clear success/failure indication.
- Automatically relock after a defined period.
- Allow authorised password changes.
- Maintain the password after power interruption if designed for persistent storage.
- Provide a physical emergency mechanism or recovery procedure.

Completion:
The locking mechanism reliably distinguishes authorised and unauthorised access.

05. MINI WEATHER STATION

Job:
Measure and display environmental conditions.

Core Work:
Collect measurements from environmental sensors and present usable data.

Functions:

- Measure temperature.
- Measure humidity.
- Measure atmospheric pressure.
- Measure light intensity.
- Display current measurements.
- Update measurements periodically.
- Record historical measurements.
- Detect unreasonable sensor readings.
- Calculate useful derived values where applicable.
- Provide a clear data interface.
- Continue operating for extended periods.

Completion:
Produces stable, readable environmental measurements and preserves useful historical data.

06. OBJECT / PEOPLE COUNTER

Job:
Automatically count objects or people passing through a defined area.

Core Work:
Detect movement through an entry/exit point and maintain an accurate count.

Functions:

- Detect an incoming object/person.
- Detect an outgoing object/person where applicable.
- Maintain the current count.
- Avoid counting the same object/person multiple times.
- Handle multiple consecutive movements.
- Display the count.
- Record counting events.
- Detect ambiguous or invalid detections.
- Allow the count to be reset by an authorised action.
- Continue functioning under normal lighting and movement variations.

Completion:
Produces a reliable count across repeated real-world trials.

07. OBSTACLE-AVOIDING ROBOT

Job:
Move autonomously while detecting and avoiding obstacles.

Core Work:
Combine sensing, decision-making, motor control, and mechanical movement.

Functions:

- Move forward autonomously.
- Detect obstacles.
- Stop or change direction before collision.
- Select an alternative path.
- Control left and right motors independently.
- Handle obstacles from different directions.
- Recover from temporary dead ends where possible.
- Detect abnormal sensor readings.
- Stop safely when a critical fault occurs.
- Operate continuously without human control.

Completion:
Navigates an unknown obstacle-filled area without collisions or manual steering.

08. LINE-FOLLOWING ROBOT

Job:
Follow a predefined path automatically.

Core Work:
Detect a line and continuously correct the robot's movement to remain on it.

Functions:

- Detect the track.
- Determine deviation from the track.
- Adjust motor speeds according to deviation.
- Follow straight sections.
- Follow curves.
- Handle intersections according to defined rules.
- Recover after losing the line.
- Maintain stable movement at different speeds.
- Detect abnormal sensor conditions.
- Stop safely when required.

Completion:
Completes a defined track repeatedly with consistent performance.

09. OBJECT-SORTING MACHINE

Job:
Automatically identify and separate objects according to defined characteristics.

Core Work:
Detect an object's properties, classify it, and physically route it to the correct location.

Functions:

- Detect incoming objects.
- Detect defined object properties.
- Classify objects according to predetermined rules.
- Select the appropriate destination.
- Physically move/sort the object.
- Handle objects arriving consecutively.
- Detect unknown or unclassifiable objects.
- Prevent jams where possible.
- Count sorted objects.
- Record sorting results.
- Provide a safe emergency stop.

Completion:
Repeatedly identifies and physically separates test objects with measurable accuracy.

---

10. SELF-BALANCING ROBOT

Job:
Maintain its own upright position without external support.

Core Work:
Measure its orientation, calculate corrective movement, and continuously control its motors.

Functions:

- Measure tilt and angular motion.
- Estimate the robot's current orientation.
- Determine the required corrective movement.
- Control both motors independently.
- Continuously correct forward/backward falling.
- Recover from small disturbances.
- Maintain balance for an extended period.
- Detect excessive tilt.
- Enter a safe state after losing balance.
- Allow balancing parameters to be adjusted.
- Provide measurable stability/performance data.

Completion:
Maintains upright balance autonomously and recovers from controlled disturbances.

ARTIFICERS STANDARD

A project is not complete because the prototype works once.

Every project must include:

- Functional hardware.
- Functional software/firmware where required.
- Proper power management.
- Mechanical stability where applicable.
- Defined inputs and outputs.
- Error/fault handling.
- Repeatable operation.
- Testing under multiple conditions.
- Measurable performance.
- Basic documentation.
- Clear explanation of how and why the system works.

Rule:
Build it. Break it. Find out why. Fix it. Test it again.

A successful demonstration is the beginning of completion, not the definition of it.

251. ARTIFACT

Description:
A modular and reconfigurable engineering system whose final form is not predetermined. Hardware and software modules can be added, removed, replaced, or rearranged, allowing the system to develop different capabilities over time.

Core Objective:
Build a system capable of detecting, identifying, integrating, configuring, testing, and using different modules while maintaining operation when possible despite module failures.

Possible Modules:

- Computing
- Power
- Sensors
- Actuators
- Communication
- Mechanical structures
- AI/software
- Tools
- Experimental modules

Key Capabilities:

- Automatic module identification
- Modular hardware architecture
- Modular software architecture
- Dynamic reconfiguration
- Fault detection and isolation
- Capability discovery
- Plug-and-play expansion
- Inter-module communication
- Adaptive resource management

Purpose:
The project is not intended to produce one predetermined machine. It is intended to create an architecture capable of becoming different machines or systems depending on the modules available.

Difficulty: Research / Long-term

Disciplines:

- Robotics
- Embedded Systems
- Electronics
- Mechanical Engineering
- Software Engineering
- Artificial Intelligence
- Control Systems
- Communication Systems
- Systems Engineering

Status: Planned
